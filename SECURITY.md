# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately through GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/GillySpace27/fluxpype/security/advisories/new) of this repository
(owner: GillySpace27). Please include the affected file or version, steps to reproduce, and the
impact you expect.

## Supported versions

Only the latest release and the `dev` branch receive fixes.
